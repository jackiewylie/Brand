System Overview

This document is the Phase 4 production identity specification for the Vigil by Lede professional brand. It establishes every production decision — logotype, logomark, type, color, components, motion, and partner system — that Phase 5 (website) and Phase 6 (product application) will implement directly. Logomark — The Step

The Step is the brand's motion arrested into a mark. An instrument line travels across a surface and steps down at the exact moment an event occurs — a filing, a signal, a breach. The node in Flare orange marks that moment. At rest, the Step is the simplest possible mark of something that happened.

Typography rules

  • D4 (binding): only two typeface families are authorized — IBM Plex Mono and Schibsted Grotesk. No third family may be introduced without a formal Phase 4 token amendment. This includes serif reading faces; Schibsted Grotesk at 16px/lh 1.80 is the D4-compliant reading register.
  • IBM Plex Mono is always the display face in product interfaces. Lede Serif / Instrument Serif does not appear in Vigil product UI — it is reserved for the consumer Lede brand and brand-only marketing surfaces.
  • IBM Plex Mono weight 700 is authorized at display scale (≥18px) only. Data values use 400 or 500. No 700 weight in the data layer.
  • All data columns use font-variant-numeric: tabular-nums to prevent digit-width jitter as values change.
  • Body text columns should be 55–75 characters wide. Enforce with max-width on the text container.
  • Headings at ≥18px use text-wrap: balance to prevent orphans.
  • Schibsted Grotesk replaces Hanken Grotesk per token spec v2.0.0 weight remap: 300→400, 400→400, 500→500, marketing-emphasis→700.

09

Motion

Motion in the Vigil product system is the-line-steps: one gesture per event occurrence. The instrument line draws and the node plants. Everything else is still. The product does not animate unless something happened.

Gesture name
the-line-steps
Line draw
550ms, left-to-right, cubic-bezier(0.2, 0, 0, 1). The instrument line draws from its current position to the step point.
Node appear
200ms after line draw completes. Scale 0→1, cubic-bezier(0.2, 0, 0, 1). The Flare orange node appears at the terminal point of the step stroke.
Repeat rule
Once per event. The gesture fires on event creation, not on scroll, hover, or page load. Never looping in product UI.
Number animations
Numbers tick like tape — counter-style increment on value change. Duration: 300ms. Easing: linear. tabular-nums enforced to prevent layout shift.
Ambient motion
Permitted on brand-only marketing surfaces (website hero, brand film). Prohibited in product UI. "Quiet surfaces do not move."
prefers-reduced-motion
All animations render final states immediately. No transitions. No counter increments — show final value directly. This is a hard requirement, not a suggestion.
Hover states
Surface elevation change only (bg1→bg2) on cards. Button active: scale(0.97), 80ms, no easing. No color animation in resting→hover transitions.
