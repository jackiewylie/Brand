Iconography Direction

Line icons only. Precise geometry. No fills, no gradients. Stroke width: 1.5px at 24x24 viewBox. Signal icons — those marking an active state or key action — use brand gold. Standard UI icons use currentColor at text-muted opacity.

08

Don'ts

These violations have been observed in the wild. Each one breaks system integrity. If any output contains one of these patterns, it must be corrected before shipping. This is not a style preference — it is a system rule.

No rectangular buttons All buttons are rounded-full without exception. Sharp corners are not in the system vocabulary.
A card component
No borders on cards Elevation is achieved through surface stepping only. A visible border on a card is always wrong.
A panel element
No box-shadow The shadow utility is not part of this system. Elevation comes from background color stepping, never from shadow.
text-[#3a7bc8] p-[17px] w-[342px]
No arbitrary Tailwind values Square-bracket notation bypasses the token system. Use only named token classes from the defined config.
A section panel
No gradient backgrounds Solid surface tokens only. Gradients create visual noise and break the precision instrument aesthetic.
Bold headline text
No weight above 500 font-semibold (600), font-bold (700), font-extrabold (800) are prohibited. The system uses 300, 400, 500 only.
Active signal
No non-token colors Every color must map to a defined token. Blue, cyan, purple, green accents outside the token set are not permitted. Brand gold is the only accent.
alfa
No wordmark on gray surfaces The wordmark lives on dark surfaces only — surface-primary, secondary, or tertiary. Mid-tone, gray, or light backgrounds are never acceptable.
