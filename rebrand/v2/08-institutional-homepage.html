SOC 2 Type II Certified

Full SOC 2 Type II certification covering security, availability, processing integrity, confidentiality, and privacy. Annual audit cycle. Certification documentation available under NDA during procurement due diligence.

FINRA-Aware Architecture

Alfa's data handling, output stamping, and audit infrastructure were designed with FINRA's books-and-records requirements in mind. All model calls are logged, timestamped, and maintained with retention policies compatible with FINRA Rule 4511.

Enterprise SLA

SSO and Access Controls

SAML 2.0 and OIDC SSO integration for enterprise identity providers. Role-based access controls with seat-level permissioning. API key management with scoped credentials and rotation policies compatible with enterprise secrets management.

Alfa Platform — Python SDK Python 3.10+ 
# Install: pip install alfa-platform
import alfa

# Initialize with your API key
client = alfa.Platform(
    api_key="sk-alfa-...",
    environment="production"
)

# Get earnings signal for a ticker
signal = client.earnings.signal(
    ticker="AAPL",
    quarter="Q3-2025"
)

# Every response is stamped
print(signal.conviction)        # "HIGH"
print(signal.eps_surprise)      # +0.08
print(signal.guidance_revision) # "RAISED"
print(signal.provenance.model)  # "alfa-finance-v4.2"
print(signal.provenance.inputs) # [...14 sources]

# Subscribe to real-time event bus
async with client.events.stream(
    tickers=["AAPL", "MSFT", "NVDA"],
    event_types=[
        "earnings_signal",
        "guidance_revision",
        "consensus_move"
    ]
) as stream:
    async for event in stream:
        handle_signal(event)

# Register portfolio for monitoring
monitor = client.portfolio.monitor(
    holdings=[
        {"ticker": "AAPL", "weight": 0.08},
        {"ticker": "MSFT", "weight": 0.06},
    ],
    webhook_url="https://your-infra.com/alfa",
    conviction_threshold="HIGH"
)
