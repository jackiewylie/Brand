Stress Test 04

the-line-steps Animation

Four stages of the signal animation: pre-event (idle), line mid-draw, full step complete (final state), and live demo loop. Stage 4 loops in this demo context only — production fires once per event, never loops. prefers-reduced-motion renders Stage 3 final state immediately.

Pass

Stage 1 — Pre-event

No event has occurred. The line has not started drawing. The node does not exist.

Stage 2 — Line Drawing

Line draws left-to-right. No node yet. No descent until line reaches the step point.

550ms · cubic-bezier(0.2,0,0,1)

Stage 3 — Complete

Line complete. Descent drawn. Node popped. This is the resting final state — never animated again.

Node at 770ms · 200ms pop

Stage 4 — Live Demo loop only

Production: fires once per event, never loops. Demo: cycles every 2.5s to show full sequence.

550ms + 220ms + 200ms = 970ms total

prefers-reduced-motion: renders Stage 3 final state immediately, no draw animation.
