Naming Funnel — Three Finalists

Phase 2 produces three post-Alfa professional product name finalists meeting all seven D5 criteria. Phase 3 blind gauntlet selects one. All three are unencumbered by existing professional-brand-gauntlet commitments — none has been recommended or pre-selected. The Phase 3 evaluator chooses blind.

Phase 1 D5 criteria (verbatim from Phase 1 §02 decision table):
  1. Entity clean — does not share a name with any entity on the OFAC SDN list, EU Consolidated Sanctions List, or UK OFSI list; does not return a sanctioned financial institution in standard entity-check databases
  2. Fund-manager legible — can appear in a board meeting, a prime broker agreement, or a fund auditor's vendor list without explanation; not a consumer-brand word; not an editorial metaphor
  3. Works with "by Lede" — the compound "[Name] by Lede" reads cleanly in both spoken and written form; "[Name] Platform" and "Powered by [Name]" must both work; "Ask [Name]" should work for the agent interface
  4. Finance-adjacent but not finance-literal — evokes precision, coverage, signal, or timing without being a common finance term already in use as an asset class, metric, or product category
  5. Speakable, 1–2 syllables preferred — pronounced without ambiguity in an English-speaking financial context; no silent letters; no homophone tax; maximum 2 syllables for the master name
  6. Trademark class 36/42 viable — can be registered as a trademark in class 36 (financial services) and class 42 (software/SaaS) in US, UK, and EU without high-conflict opposition risk — must be tested, do not assume
  7. Product lexicon available — "A [Name]" can be a noun for a thing the product produces or detects; "Your [Name]s" must be a natural plural in a professional research context

Phase 1 D5 failure examples (names that cannot advance without a formal D5 amendment): Standfirst (criterion 2: editorial metaphor; criterion 5: obscure outside UK newsroom), Bellwether (criterion 4: finance-literal signal stock; criterion 5: 3 syllables + misspelling tax "bellweather"). These names remain in the red-team document as bench research but do not qualify as D5-compliant finalists.

In professional investment intelligence: the brief is the platform's primary output, the document that precedes every decision. It is finance-adjacent without being finance-literal: it belongs to the information domain, not the asset class domain.

Phase 2 → Phase 3 Handoff

What Phase 3 receives as confirmed inputs vs. what it decides.

Confirmed — Phase 3 inherits as inputs
  • Four complete creative territories (A, B, C, D), each with visual specification, FM-04 verdict, Bloomberg answer, and logomark direction
  • Three naming finalists (Brief, Vigil, Bearing), each evaluated against Phase 1 D5 criteria verbatim with explicit condition notes
  • FM-04 clear on A, B, C. D is conditional on Phase 4 test.
  • Territory D carries two open conditions: FM-04 test and D7 amendment for dawn amber
  • All Phase 1 decisions (D1–D7) remain confirmed — Phase 3 does not relitigate them
  • The Powered/Powered+ naming syntax three-way fork (Phase 1 issue #2) is a Phase 3 decision — see naming funnel format below
Phase 3 decides
  • One creative territory selected — from the four, blind to Phase 2 recommendation. The selection is the Phase 3 deliverable. If Territory D is selected, the selection must include explicit acceptance of FM-04 conditional.
  • One name finalist selected — from Brief, Vigil, or Bearing, subject to trademark clearance in class 36 and class 42. The selection is provisional until counsel clears it. If the preferred name fails clearance, the second-preferred activates per the bench priority the evaluator states.
  • Powered/Powered+ attribution syntax — three-way fork decision required. The three options (each with a distinct application scenario): (1) "Powered by [Name]" — partner uses the post-Alfa product name; (2) "Powered by [New Name]" — partner uses the future successor name if post-Alfa name is transitioning; (3) "Powered by Lede" — partner uses the company name rather than the product name, appropriate when the product name is not yet established or when the partner's brand would be better served by the company-level endorsement. Phase 3 must specify which formulation a partner uses in which scenario, or explicitly defer to Phase 4 with a stated reason.
  • Transition-period co-presence answer — Phase 3 confirms which territory's direction handles the Boosted.ai + Alfa + Lede simultaneous-in-market scenario, and whether the selected territory requires a Phase 4 amendment to the co-presence rules

Phase 3 Blind Selection Format

The Phase 3 evaluator reviews the four territory pages in isolation — each page is designed in its own aesthetic, so the evaluation is visual as well as strategic. The format for Phase 3 output:

  • Selected territory (A / B / C / D) with explicit rationale against Phase 1 D1–D7 decisions
  • Selected name finalist (Brief / Vigil / Bearing) with explicit rationale against Phase 1 D5 criteria, plus stated bench priority if preferred name fails trademark clearance
  • If Territory D selected: explicit acceptance of FM-04 conditional and D7 amendment requirement
  • Powered/Powered+ syntax decision: which formulation, and when
  • Phase 3→4 handoff: one page of inputs Phase 4 inherits as confirmed
